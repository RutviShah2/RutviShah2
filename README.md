## `// about`

I'm a **Computer Science undergraduate** working at the intersection of **data science, machine learning, and software development**. I like taking raw, untidy data, finding the patterns in it, building models around them, and shipping the result as something people can actually use.

My current focus is on strong fundamentals in **DSA, Python, SQL, and Machine Learning**, paired with projects that turn those skills into working applications.
